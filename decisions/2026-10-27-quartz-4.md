## Değişiklikler
- `Quartz.Extensions.DependencyInjection` ve `Quartz.Extensions.Hosting` 4.x'te `Quartz` paketine birleştirildi (rehber:
  "Still remove them") → CPM'den ve sağlayıcıdan kaldırıldı.
- `IJob.Execute(IJobExecutionContext)` → `ValueTask Execute(IJobExecutionContext, CancellationToken)` (adaptör).
- `IScheduler.ScheduleJob(job, trigger, ct)` → `ScheduleJob(job, trigger, ScheduleJobOptions, ct)`;
  `CheckExists` → `Exists`.
- **Kck public API kırılması:** `AddKckBackgroundJobsQuartz(Action<IServiceCollectionQuartzConfigurator>?)` →
  `AddKckBackgroundJobsQuartz(Action<IQuartzBuilder>?)` (`src/Providers/Kck.BackgroundJobs.Quartz/CompatibilitySuppressions.xml`, CP0002).
- Tüketiciyi etkileyebilecek Quartz 4 davranışları (geçiş rehberine): saat dilimi verilmeyen cron tetikleyicisi
  `DefaultTimeZone` kullanır (4.7 notu), misfire varsayılanı `DefaultMisfireHandling` (4.6), kimliksiz iş/tetikleyici uyarı
  4030 (4.6; Kck adaptörü her işe kimlik veriyor), iptal edilen çalıştırma `Cancelled` olarak kaydedilir (4.4).

## Doğrulama (2026-10-27)
- RED: sürüm yükseltilince CS0246 (`IServiceCollectionQuartzConfigurator`) + CS0535 (`IJob.Execute`).
- GREEN: `Kck.BackgroundJobs.Quartz.Tests` 8/8, yeni gerçek-zamanlayıcı testi dahil (DI üzerinden iş tetiklenir); mutation
  denemesi: adaptör işi çağırmayınca test zaman aşımıyla düşer.
- Solution: `restore --locked-mode` temiz, Release build 0 hata, birim testleri 0 başarısız, paket doğrulama yalnız
  belgeli CP0002 ile geçer.
- README örneği gerçek uygulamada: 3,5 sn'de 4 çalıştırma (1 kuyruk + saniyelik cron).
