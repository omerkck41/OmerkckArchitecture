# API reference

Generated from the XML documentation of the `Kck.*` packages. Start from a namespace in the navigation:

- `Kck.*.Abstractions` — the contracts (interfaces, options, models) your code depends on.
- `Kck.*` providers — the implementations and their `AddKck*` registration methods
  (`Microsoft.Extensions.DependencyInjection` namespace).
- `Kck.Bundle.*` — one-call defaults for a hosting model.

For how the pieces fit together, read the [documentation](../docs/README.md).
